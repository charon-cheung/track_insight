# 数据与指标合同 v1

schema_version = 1；metric_version = 1.0-duration-left-cells。

## 时间与身份

绝对时间均在 C++ 使用 int64 纳秒，JSON 使用十进制字符串。保留 record/header/send 时间、来源 sequence、epoch 和时间选择依据。展示使用相对于 origin_ns 的数值秒，刻度最多到毫秒；完整日期在悬停时显示。保存生成机器本地时区偏移的变化点，浏览器不使用其自身本地时区。

P 是每条路径发布快照，重复几何仍各有编号；R 是独立 lattice planner 请求，失败请求可以没有 P；C 是控制器 session 内的 revision；N 是有足够日志或 action 生命周期证据的导航任务；E 是候选执行窗口。禁止通过数字相等将这些编号等同。

共享路径 header stamp、frame、点数必须唯一才能确认 P/C 身份。首个控制输出须有可与实际指令对应的 command_stamp_ns，才能确认开始边界。任务结果或下一个已证实控制输出用于确认结束边界。只有三个确认条件同时成立才生成 confirmed 区间统计。其余为 inferred，独立汇总。

同时存在导航 action 和日志时，action 控制生命周期；唯一、相近且同轮关联日志中的目标可补充目标坐标，不制造第二个导航任务。含重叠时钟 epoch 的模糊关联保留为无任务归属。

## 有效分析单元

所有窗口都是 [start, end)。几何以有效位姿样本构造有界左端采样单元；TF 缺口、定位跳变和未知尾部不获得有效权重。

速度在指令变化、指令失效和反馈时间点处分割。指令因果零阶保持，默认最长 200 ms；反馈仅在有效且间隔不超过 200 ms 的两点之间插值。左右端参考系、参考点和 epoch 必须相容。相同 header 时间的多条指令使用记录交付时间区分，缺少证据或同时交付冲突值时排除。

正式速度残差为 feedback - command，不平滑、不做自动时延平移。独立原始指令/反馈曲线可以继续显示，不能把残差配对缺失等同于原始两条曲线同时缺失。下游速度只作为另一条命令来源保存，不当作测量反馈。

## 统计定义

对有效单元 i，时长为 dt_i，左端误差为 e_i：

- bias = sum(e_i * dt_i) / sum(dt_i)
- MAE = sum(abs(e_i) * dt_i) / sum(dt_i)
- RMSE = sqrt(sum(e_i² * dt_i) / sum(dt_i))
- P95 为 |e| 按有效持续时间加权累计达到 95% 时的最小误差值。
- Max 为有效采样误差的最大绝对值，保存定位时间。
- coverage = 有效时长 / 排除任何数据之前的候选时长。
- 超阈值持续时间与最长连续超阈值时间使用同一有效单元；缺口会打断连续性。

时间重叠不重复计权；导航统计重新汇总非重叠单元，不平均各路径的 RMSE 或 P95。阶段未知的缺口仍进入 unknown 阶段分母。零时长窗口的 coverage 为 null。

位置指标分开保存：有符号横向误差、到所选有限线段的距离、到路径终点的距离。越过终点不会因横向误差小而隐藏端点偏差。纯旋转路径的横向方向未定义，因此横向指标不可用，仍可评价到固定位置的距离。

路径匹配限制进度历史；交叉、重复路径的分支不能可靠区分时排除该段匹配。目标 yaw 仅取同一控制器会话和 revision 下、有效邻域内的明确日志字段；不使用路径切线代替。

## 任务终点与停车

goal_position_error 使用已记录导航结果附近、有效时间范围内的定位和任务目标。它与任意路径窗口结束时的 endpoint_distance 不同。

stopped_residual_error 和 stopped_drift 需要结果后连续低速度窗口及足够定位数据。默认静止阈值为平面 0.02 m/s、角速度 0.03 rad/s，窗口 1 s，均可配置。

settling_time 仅在明确配置 terminal_position_m 且存在同时满足静止及目标容差的连续窗口时给出，定义为记录结果到该支持窗口起点的时间。该值不是未记录的控制器内部 settle 状态。数据不足或未配置容差时为 null。

标量指标使用 value；时间序列统计使用 rmse/mae/bias/p95/max。瞬时指标不伪造持续时长或 100% 时间覆盖率。

## 质量与可追溯性

每个指标独立保存单位、质量、不可用原因、候选与有效时长、样本数、排除原因计数。零值只表示观测或计算所得零，不能代替未知。

导航事件、数据质量事件、跟踪阈值/停滞观测和最大值定位分开分类。重规划不是跟踪异常。反复残差换向只报告曲线现象，不推断控制器超调根因。

正式指标使用全部有效分析单元。网页可降采样，但保留各显示桶极值、有效性边界及缺口；游标查找使用完整分析数组。原始来源时间和日志行号保存在 analysis.json，可单独重渲染。
